# Atlas — Portfolio Research and Risk Platform

## Atlas investment product

The [Atlas product workspace](product/README.md) contains the actively developed portfolio-research foundation, run instructions and detailed program manual. Target: a private read-only/paper prototype by December 12, 2026. Current scope is local synthetic research and risk workflows, not a live trading service.

Start with the [program and roadmap](product/docs/PROGRAM.md), [requirements](product/docs/REQUIREMENTS.md), and [security gates](product/docs/SECURITY.md). The existing root `src/` is the legacy quantum-inspired experiment; it remains isolated and its results are not validated evidence of investment performance.
