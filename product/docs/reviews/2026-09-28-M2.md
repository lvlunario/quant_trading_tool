## Concept: provenance is a chain, not a citation string

A URL tells a reader where to look. A provenance chain additionally binds the
exact bytes, the time they became available, the security and dataset they
belong to, the transformation version and the value produced. Atlas now checks
one more link in that chain; a plausible citation cannot silently support a
different security, file revision or metric value.
