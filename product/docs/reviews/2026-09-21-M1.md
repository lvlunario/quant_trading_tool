## Demo

From `product/`, run:

```bash
python -m atlas --broker-demo
```

Expected: status `reconciled`; two accepted row outcomes; equal input and mapped row counts; selected profile `MAP_SYNTHETIC1`; rounding policy `exact`; and readiness explicitly stating `not Fidelity-validated`. The output omits symbol, ticker, quantity and price fields. It uses invented in-memory values, makes no file/network call, stores nothing and cannot place orders.

Concept to inspect: a **mapping profile** separates a source file's labels from Atlas's canonical meaning. A source header can change without silently changing what an equity, cash row or numeric field means. Version, currency and rounding are part of the profile because an unrecorded interpretation change can alter portfolio totals.
