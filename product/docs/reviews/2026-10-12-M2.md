## Concept: evidence decomposition

A single green demo can hide several red production prerequisites. Evidence
decomposition keeps each claim narrow: synthetic conformance shows the software
path is reachable; source rights show use is permitted; licensed data supports
the content; acceptance authorizes progression. None substitutes for another.
